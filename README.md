# EE435 Control Systems Lab

An interactive teaching lab for first- and second-order control systems.

Explore pole locations, time responses, symbolic output equations, steady-state error, and step-response measurements. Everything runs in the browser; no server or API key is needed.

## Publish with GitHub Pages

Use a public repository on GitHub Free. In Settings > Pages, choose Deploy from a branch, then select the main branch and the root folder.

The entry point is `index.html`. The `.nojekyll` file keeps the deployment as a plain static website.

## Use offline

Download `index.html` and open it in a browser.
